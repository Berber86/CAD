# Title Survey AI 4.76 — подписи сторон на печатном черновике

Николай, поправили расстояние между румбом и размером стороны на дополнительном чертеже. Раньше наши пробелы иногда размахивались дальше самой стороны — теперь стараемся держать их в рамках 🙂

- На печатном черновике лишние пробелы между румбом и расстоянием сокращаются. По возможности подпись оставляет запас примерно по 10% длины стороны с каждого края.
- Сами цифры, румбы, высота текста, стиль и границы участка не меняются. Основной чертёж сохраняет прежнее оформление.
- Если даже с одним пробелом текст не помещается с запасом или AutoCAD не позволяет измерить ширину, данные не обрезаются: в отчёте будет отметка для проверки.

Это относится к новому построению: уже нарисованные подписи автоматически не заменяются. Проверено автотестами и на имитации AutoCAD; в настоящем AutoCAD и с вашим шрифтом `LETTER` ещё нужно проверить.
