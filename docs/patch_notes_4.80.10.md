# 4.80.10 — автопоток Staten Island

На Шаге 0 добавлена отдельная кнопка: адрес → NYC Portal (Borough, Block, Lot и
соседи) → сайт Richmond County → полные PDF → многоконтурный поиск и разбор.
Отрисовка в AutoCAD остаётся отдельным действием пользователя. Запуск может быть
платным, а уже отправленный запрос после остановки может завершиться и быть
оплачен. Быстрый режим поиска адреса для автопотока запрещён из-за непроверяемой
подсказки/CAPTCHA; используйте надёжный или оптимальный.

Сайт Richmond County не вызывается ни автоматическим, ни ручным сбором при
неизвестном или другом Borough. При частичном сборе, недоступном PDF, изменении
адреса/BBL и низкой уверенности по соседям автоматический переход прерывается.
Старый поиск описания и создание обрезанных PDF пропускаются именно в новом
автопотоке; прежний ручной сбор сохраняет своё поведение. В multi передаются
только полные PDF из текущего результата сбора, а не старые файлы из папки.
Модельные результаты и соседей по карте необходимо проверять по исходникам.
