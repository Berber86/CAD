# 4.80.12 — DWG в папке описаний, включая неполную отрисовку

После ручного запуска отрисовки результата автопотока программа сохраняет
документ AutoCAD прямо в папку, где находятся собранные PDF. Новые папки для
DWG не создаются. Пример: `01_описания/lot_30_<случайный-суффикс>.dwg`.
Для параллельных запусков имя резервируется отдельным служебным файлом;
проверяются существующие DWG, а суффикс генерируется случайно. После работы
служебная отметка удаляется; при ошибке частично созданный DWG остаётся.

`SaveAs` выполняется после попытки отрисовки, даже если отдельные объекты или
планы не построены, разбор неполный либо номер из описания не совпадает с
номером портала. Имя использует снимок Lot портала для исходного автопотока,
а если номер отсутствует — `lot_unknown_<суффикс>.dwg`. Это имя не является
подтверждением номера участка. Статус и журнал сообщают и об ошибке отрисовки,
и о сохранённом файле; результат нужно проверить. При сбросе отменяется ещё не
начатое сохранение. Если AutoCAD недоступен или сам отказал в сохранении,
программа сообщает об ошибке — сохранить файл в таком случае невозможно.
Отрисовка, как и прежде, начинается вручную. Проверки проведены на имитации
COM; реальный AutoCAD в этом окружении недоступен.
