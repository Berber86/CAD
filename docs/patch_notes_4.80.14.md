# 4.80.14 — Слои и стили текста на печатном черновике (п. 5)

На отдельном чертеже нашего участка («черновик для печати», сдвиг +1000 по X)
подписи Шага 1 теперь разделяются на две группы:

- **Группа 1 — основные названия улиц** (фасадная улица и пересекаемая улица
  или несколько пересекаемых улиц): слой `LETTER` (цвет `ByLayer`, без
  принудительного наклона), стиль `MtXpl_Times_New_Roma`, высота `4`.
- **Группа 2 — все остальные подписи линий участка** (румбы и длины, примечания
  `PARALLEL WITH` / `AT RIGHT ANGLES`, прежние названия `(FORMERLY ...)`,
  ширина/примечания улиц, расстояние привязки до перекрёстка, `PARTY WALL`,
  дуги/подписи углов): слой `M-TAX-DIM`, стиль `Romans` / `ROMANS` (высота `2`
  для сторон и `1.6` для остальных).

Стили `MtXpl_Times_New_Roma` и `Romans` / `ROMANS` ищутся в таблице `TextStyles`
без учёта регистра и при наличии в DWG не изменяются. Если нужный стиль
отсутствует, он создаётся с соответствующим шрифтом (`Times New Roman` / `times.ttf`
для `MtXpl_Times_New_Roma`, `romans.shx` для `ROMANS`) и выдаётся предупреждение
для сверки с шаблоном. При ошибке создания слоя или стиля отрисовка
останавливается до добавления объектов в чертёж.

Основной чертёж (с соседними участками и меткой `LOT …`) и соседние контуры
оставлены без изменений (`M-TAX-DIM` / `LETTER`). В Шаге 2 слой `LETTER` добавлен
к текстовым препятствиям (`text_obstacle_layers`).

**Отложено (парсер нескольких пересечений):** legal description может
описывать два и более пересечения (например, участки на `Hylan Boulevard`).
Полную доработку `llm_parser.py` для извлечения и раскладки нескольких
пересекаемых улиц необходимо выполнить отдельно (`docs/customer_rules.md`);
сейчас выполнена лёгкая часть на стороне черновика (`_is_primary_street_label_kind`),
чтобы любые основные названия улиц (включая `cross-street-2`, …) сразу
попадали на `LETTER` / `MtXpl_Times_New_Roma`.

Проверки выполнены офлайн на автотестах с COM-заглушкой AutoCAD; живой AutoCAD
в этом окружении не запускался.
