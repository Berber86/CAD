# 4.81.14 — Шаг 0 для четырёх районов через ACRIS

По просьбе пользователя (пошаговое обучение по его образцам страниц):

- Шаг 0 теперь собирает не только Staten Island. Источник выбирается по
  району, правила сайтов не смешиваются:
  - Staten Island / Richmond County — Richmond County Clerk, как раньше
    (первый настроенный вариант, не тронут);
  - Manhattan, Bronx, Brooklyn, Queens — ACRIS (`acris.py`,
    `acris_viewer.py`). Неизвестный район по-прежнему отклоняется до
    обращения к любому сайту.
- Цепочка ACRIS (вся подтверждена настоящими образцами пользователя):
  список — прямым POST на `BBLResult` сразу с `hid_max_rows=99` (руками
  выпадающий список «99» больше нажимать не надо), страницы листаются кодом;
  выбор Deed/Mortgage — тем же правилом, что у Клерка; `document_id` — по
  CRFN из официального NYC Open Data (ACRIS Master); документ — читалка в
  настоящем браузере: дискета Save → OK («All» уже выбрано), PDF падает в
  «Загрузки» и дальше идёт общим руслом (страницы описания, имя
  `OUR LOT … NEW.pdf`, паспорт, `_manifest.json`).
- Клики читалки калиброваны по скриншоту пользователя: дискета — картинка,
  её точка = правый край текста «73%» + 134 px; каждый шаг проверяется
  снимком окна (OCR), при неудаче — честный ручной шаг со ссылкой, а не
  слепые повторные клики.
- Пользователь подчеркнул: сценариев автоматизации Шага 0 всего три, пока
  прописан только первый (ACRIS). Остальные — по его следующим шагам.

Проверки: офлайн — `tests/test_acris.py`, `tests/test_acris_viewer.py`,
`tests/test_acris_intake.py` (проход на настоящей странице Manhattan
731/53), GUI-ворота районов в `tests/test_gui_smoke.py`. Живая проверка
кликов и прямого POST — только на машине пользователя (из среды разработки
ACRIS режет роботов страницей отказа).
