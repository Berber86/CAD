# 4.81.16 — ACRIS на живой машине: даты колонок и SSL к NYC Open Data

Живой сбор у пользователя (Manhattan, block 731, lot 53) показал две
поломки; список при этом читался верно (6/22/10 строк по лотам):

- Все даты — «без даты». На живой странице заголовки таблицы результатов
  пишутся не как в сохранённом образце (виджет сортировки, «Recorded/Filed»
  без пробелов), а разбор требовал дословного совпадения. Теперь заголовки
  сопоставляются терпимо (сжатый вид, начало слова), виджет сортировки
  вырезается и без `<tbody>`, а даты читаются также в ISO, через точки и
  месяцем словом. Если даты всё равно не прочитаются, журнал Шага 0
  напечатает образец строки — его можно прислать для разбора.
- `document_id` не получался: Python на машине пользователя не нашёл
  издателя сертификата data.cityofnewyork.us
  (`CERTIFICATE_VERIFY_FAILED`). Оба сетевых запроса ACRIS (список и NYC
  Open Data) при именно этой ошибке повторяют один раз с bundled certifi
  CA — тот же приём, что уже работает в `app_updater.py`.

Проверки: офлайн — варианты живых заголовков на настоящей странице,
форматы дат и повтор с certifi в `tests/test_acris.py`. Живой повтор —
на машине пользователя.
