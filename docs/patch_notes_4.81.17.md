# 4.81.17 — Автопоток: подсказка портала может грузиться дольше двух проверок

Повторный живой запуск (417 WEST 33RD STREET, надёжный режим) снова
остановился на подсказке, хотя список на скриншоте открыт и первая строка
верная. Сокращения были исправлены в 4.81.15 — значит, проверки успевали
закончиться раньше, чем портал показывал список (портал при этом ещё и
сообщал «Could not retrieve current location»), либо OCR читал строку с
шумом.

- Ожидание подсказки делает второй цикл проверок вместо одной пары;
  остановка по-прежнему честная, без клика вслепую.
- Сравнение подсказки терпит OCR-шум: склеенное «417W», потерянный тип
  улицы («St»). Номер дома, направление и номер улицы сверяются всегда —
  чужая подсказка не пройдёт.
- При неудаче журнал теперь печатает, что именно OCR видит под полем
  адреса («На снимке первая подсказка: …»), чтобы следующая остановка
  давала точную причину, а не догадки.

Проверки: `tests/test_nyc_portal.py` (сравнение, шум OCR, отчёт при
неудаче, обновлённые сценарии ожидания). Живой повтор — у пользователя.
