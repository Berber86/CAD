# 4.81.18 — Автопоток: проверка подсказки убрана совсем

По прямому указанию пользователя («очень сильно облегчить проверку либо
убрать её вовсе; риски не особо большие»): третья подряд живая остановка
на подсказке при открытом списке и верной первой строке. Диагностика из
4.81.17 показала: OCR подсказку видел, отсекала её геометрия «первой
строки» (запас был 6 px).

- Текстовая сверка подсказки с вводом удалена полностью (сокращения,
  токены, ключевые слова — всё). Автопоток ждёт только сам факт выпавшего
  списка: строка с цифрой под полем адреса, не равная самому полю ввода;
  числа на карте справа по-прежнему не считаются.
- Какая строка выбрана, печатается в журнал («первая подсказка портала:
  «…» — выбираю её»); выбирается она клавишами Down+Enter, как раньше.
  Дальше идут карточка участка и поля Шага 0 — человек результат видит.
- Остановка осталась только если список подсказок не появился вовсе
  после повторных проверок; диагностика «что на снимке» сохранена.
- Геометрия первой строки ослаблена и проверена на настоящих рамках со
  скриншота пользователя.

Проверки: `tests/test_nyc_portal.py` переписан под новый договор
(первая строка без сверки, ввод не считается подсказкой, стоп только без
списка, живая геометрия). Живой повтор — у пользователя.
