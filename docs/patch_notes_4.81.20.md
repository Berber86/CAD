# 4.81.20 — Подсказка по тексту, без геометрии + облегчение интерфейса №2

Автопоток. Четвёртая живая остановка на подсказке: диагностика показала,
что OCR в зоне проверки подсказку не прочитал вовсе. Геометрия из
проверки удалена окончательно: признак выпавшего списка — сам текст
подсказки («…, NY … USA»; у поля ввода и чисел карты его нет), второй
цикл ожидания стал таким же терпеливым, как первый. Клик по-прежнему
клавишами Down+Enter; какая строка выбрана, печатается в журнал.

Облегчение интерфейса, пакет №2 (выбор пользователя):
- «📥 Собрать описания» — оставлена как есть.
- «📂 Забрать свежий PDF из «Загрузок»» → «📂 Загрузки».
- «→ Передать в Шаг 1» → «→ В Шаг 1».

Проверки: `tests/test_nyc_portal.py` — узнавание подсказки по тексту на
живых строках, стоп только без списка; полный набор — в коммите.
