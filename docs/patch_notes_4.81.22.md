## Уточнения реализации

- У кнопки разбора подпись динамическая (зависит от режима). Вариант
  «✨ ИИ-разбор» применён к ИИ-режиму одиночного документа: текст при
  создании кнопки и текст в `_refresh_parse_actions`. Режимы «экономно»,
  «бесплатно», пакетный ИИ («✨ ИИ для всех PDF · платно»), набор PDF и
  альтернативная кнопка («✨ Разобрать с ИИ · расход токенов API») не
  трогались — по ним выбора не было. Сочетания Ctrl+Enter и F5 продолжают
  работать, просто не подписаны.
- Обновлён тест `test_gui_smoke.py`: подпись кнопки чертежа сверяется
  с новой.

Элементы пакета впервые взяты не только с Шага 0 (прямое разрешение
пользователя): Шаг 0 + две главные кнопки Шага 1.
