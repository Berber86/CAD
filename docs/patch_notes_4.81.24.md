# Patch Notes — 4.81.24 (23.11.2026): читалка ACRIS — HTTP 405, прогрев сессии + облегчение интерфейса №5

## Что показал живой прогон

Цепочка Шага 0 дошла дальше, чем когда-либо: портал (block 731, lot 53,
соседи 22 и 54) → список ACRIS прямым запросом (даты читаются) → выбор
Deed 2024 → `document_id=2024101000085001` → читалка открылась. Но вместо
страницы документа внутри читалки — **«HTTP 405 Method Not Allowed»**:
тулбар есть («1 of 13»), страницы нет, PDF из Save не собрался.

Причина (по устройству сайта): список мы забираем прямым запросом из
кода, поэтому в браузере нет серверной сессии поиска. Кадр читалки
(`DocumentImageVtu`) в рабочем ручном сеансе несёт критерии поиска
(`searchCriteriaStringValue`) — без них VTU страницу не отдаёт.

## Что сделано

- **Контроль страницы до кликов.** `http_error_text` ищет в OCR окна
  серверную ошибку («HTTP 405…», «Method Not Allowed»; голая цифра на
  странице документа ошибкой не считается). Сломанная читалка дискету не
  получает: два снимка с ошибкой подряд — страница признана битой.
- **Прогрев сессии и повтор.** При битой странице открывается глубокая
  ссылка поиска по тому же участку (`acris.search_form_url`:
  `…/BBL?borough=…&block=…&lot=…`) — поиск выполняется в браузере и
  создаёт сессию; затем документ открывается ещё раз. Ссылка своя у
  каждого лота (загрузчик в `_collect_deeds_acris` теперь строится на лот).
- **Дозор при сборке PDF.** Если та же ошибка появится уже после OK
  (сервер не собрал PDF), ожидание в «Загрузках» прекращается досрочно,
  а не через 300 секунд.
- **Честный ручной шаг.** Если и после прогрева страница не отдаётся —
  `ManualStepNeeded` с инструкцией открывать документ из результатов
  поиска значком просмотра (прямая ссылка тут не поможет и человеку),
  дальше — «📂 Загрузки».
- Журнал прямо пишет, что показала читалка: «читалка открылась, но
  страница документа не загрузилась: «HTTP 405 Method Not Allowed»».

Тесты: определение ошибки, сценарии «405 → прогрев → успех» (порядок
открытий: документ, поиск, документ), «405 после прогрева → ручной шаг»,
«405 при сборке PDF — стоп досрочно», URL прогрева, проброс в загрузчик.
Полный набор: **2062 passed, 14 skipped, 2 xfailed**.

⚠️ Живое подтверждение впереди: чинит ли прогрев сессию на настоящем
ACRIS, покажет следующий прогон. Если VTU и после поиска в браузере
покажет 405 — журнал это честно покажет, а ручной шаг проведёт до PDF.
