# Patch Notes — 4.81.25 (23.11.2026): страница «Данные» — очередь работ + облегчение интерфейса №6

## Новая страница «Данные» (первая вкладка)

Предваряет Шаг 0 и запускает весь автопоток пакетно, без ручных переходов
между шагами.

- **Папки работ.** Родительский каталог (все подходящие подпапки) и/или
  добавление по одной. Имя папки: номер работы, затем `#`, затем адрес
  объекта — например `1234#417 WEST 33RD STREET`.
- **Очередь задач.** Каждая подходящая папка — отдельное задание, которое
  проходит весь автопоток полностью автоматически: скачивание PDF →
  разбор → новый DWG. Программа сама создаёт в AutoCAD новый файл на
  каждое задание, рисует и сохраняет его; при любом исходе автоматически
  стартует следующее.
- **Неподходящие имена** (нет `#` или нет номера) в очередь не попадают:
  остаются в списке с пометкой «не подходит» и причиной.
- **Папка `data`** внутри каждой папки работы: туда складываются все PDF,
  обрезки, кэш, JSON и прочее; туда же — `session_log.txt` с полным логом
  сессии задания (что происходило и где поломалось).
- **Модель и рассуждения.** На этой же странице — выбор активной основной
  ИИ-модели и её уровня размышлений (общие с остальной программой).
- Сбой или тайм-аут одного задания очередь не останавливает.

## Облегчение интерфейса №6 (выбор пользователя)

- Вкладка «Шаг 0. Документы участка» → **«Шаг 0. Документы»**.
- «▶ Запустить очередь» и «☰ Роли и страницы» — оставлены как есть.

Тесты: разбор имён папок и сканирование каталога, страница «Данные» и её
контролы, очередь (сбой автопотока → ошибка + лог + следующее задание;
полный проход → DWG в `data` + закрытие документа). Полный набор перед
выпуском прогнан заново.
