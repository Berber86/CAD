# Patch Notes — 5.00 (23.11.2026): облегчение интерфейса — самые объёмные блоки

Круглая версия. Направление с этого выпуска: приоритетно режутся самые
многословные блоки интерфейса — инструкции и вводные абзацы, а не кнопки.

## Облегчение интерфейса №7 (выбор пользователя)

Применено к двум самым длинным текстовым блокам программы:

- Вводный абзац страницы подписей объектов (~35 слов: «Выполняется после
  посадки границы участка и до оффсетов. Программа читает активный
  чертёж…») → **«🏷 Подписи объектов у участка»**.
- Баннер окна спорных цифр (~28 слов: «Система НЕ меняет спорные цифры
  самовольно. Вы можете отправить модели на прицельную перепроверку…») →
  **«Спорные цифры не меняются сами. Перепроверьте, оставьте как есть или
  правьте вручную.»**
- Подпись окна выбора страниц PDF — оставлена как есть.

Плюс всё, что накопилось после 4.81 на этой ветке: страница «Данные» с
очередью работ, читалка ACRIS с контролем HTTP 405 и прогревом сессии,
угол фронтальной улицы, каталог моделей Hydra (полный перечень — в
заметках 4.81.10–4.81.25).
