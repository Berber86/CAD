# Patch Notes — 5.04 (23.11.2026): облегчение интерфейса №11 — пакет из 10

По просьбе пользователя пакеты увеличены: теперь 10 элементов за раз
(выбор пользователя по каждому).

Применено:

- Шапка вкладок: строка «Порядок работы: 0 — документы участка → 1 —
  посадка границы → 2 — подписи объектов → 4 — оффсеты» — **убрана совсем**.
- Пустой холст просмотра: «Исходное изображение не загружено. Нажмите
  «📷 Фото (JPG)…» (Ctrl+I) или «📄 PDF…» (Ctrl+O)» → **«🖼»**
- Шаг 0, подпись про «Загрузки» → **«📥 Из «Загрузок»»**
- Настройки, подпись про зашифрованный токен → **«🔒»**
- Шаг 4, статусная подсказка → **«Сначала выделите область в AutoCAD.»**
- Шаг 0, подпись быстрого режима → **«⚡»**
- Кнопка выбора фото → **«📷»**
- Настройки запуска → **«При запуске открывать»**
- Шаг 2, подсказка автопоиска границы → **«Автопоиск ищет контур границы;
  не найдёт — укажите полилинию в AutoCAD.»**
- Настройки обновления, абзац про архив → **«🔄»**

Оставлены как есть: предупреждение ИИ-автоповорота, «Экспериментальный
режим…», заголовок «Находки по данным соседей…».

ожидание в GUI-тесте обновлено под новый текст Шага 4).
