# Patch Notes — 5.08 (24.11.2026): тест моделей — полный план, оценки, статистика

Развитие секретного окна теста моделей (тройной щелчок по схеме):

- **Полный план на холсте.** Результат слота рисуется целиком — всё, что
  уйдёт в AutoCAD: контур, линии улиц, дуги углов и все подписи на своих
  местах (названия улиц, ширины проездов, расстояния и румбы сторон,
  подпись лота), точка POB. Раньше показывался только контур с длинами.
- **Оценки пользователя.** У каждого результата — оценка по шкале
  **2− … 5+** (12 градаций). Оценка сохраняется вместе с метриками
  прогона: замыкание, площадь, число сторон, секунды, токены, файл.
  Повторный выбор оценки правит ту же запись, а не плодит новую.
- **Накопленная статистика.** Книга оценок — `model_test_ratings.json`
  рядом с `config.local.json` (переживает обновления программы). Кнопка
  «📊 Статистика» открывает отдельное окно: строки по каждой модели **в
  разрезе уровня рассуждений** — число оценок, средняя оценка, среднее
  замыкание, последняя оценка; лучшие сверху. Историю можно сбросить.

Тесты: полная сцена плана, шкала и агрегация по уровням рассуждений,
книга оценок на диске, оценка и статистика в окне. Полный набор —
**2081 passed, 14 skipped, 2 xfailed**.
