# Patch Notes — 5.09 (24.11.2026): правки заказчика по Шагу 1

Со слов заказчика (Николай, 24.11.2026), по скриншоту «до/после» ручных правок.
Действует и для печатного черновика, и для обычных property line, включая
основной чертёж с соседями:

- **Названия улиц — белые.** Объектам `main-street`/`cross-street` явно
  задаётся цвет ACI 7: раньше цвет наследовался от слоя (`LETTER` в шаблоне
  заказчика красный — на скриншоте «до» названия красные). Красные вставки
  исправлений в MTEXT не тронуты.
- **Угол наклона текста — 15°.** `ObliqueAngle` стиля названий улиц
  приводится к 15° (это наклон букв, не поворот подписи): стиль `LETTER`
  основного плана и `MtXpl_Times_New_Roma` черновика, включая уже
  существующие стили в чертеже.
- **Линии улиц — голубые.** Слой `M-ROW-LINE` (уличные линии и фасадные
  стороны, в т.ч. второй фасад углового участка): явный цвет объектов
  ACI 4 вместо красного ACI 1; вновь создаваемый слой — тоже ACI 4.
  В `DEFAULT_CONFIG` и поставляемом `config.json` `layer_colors.street_row`
  приведён к 4.

Правила отражены в `docs/customer_rules.md` (новый раздел «Шаг 1: цвета
улиц и наклон текста»).

Тесты: фейковый AutoCAD — белые названия улиц, `ObliqueAngle` 15° у обоих
стилей, голубые линии `M-ROW-LINE` в основном плане и черновике; прежние
ожидания красного фасада обновлены. Полный набор — **2082 passed,
14 skipped, 2 xfailed**.
