# Patch notes 5.12 (2026-11-24)

Разбор старых логов очереди от заказчика: 3870 ARCHI (Manhattan) и 3875 (Staten Island).

## Лог задания очереди терял ход сбора — исправлено

- В присланном `session_log.txt` задания 3870 между «собираю описания» и
  «Сбор завершён: документов — 0» не было ни одной строки: строки прогресса
  фонового сбора (события `step0_progress`/`step0_portal_notice`) писались
  только в экранный журнал Шага 0, но не в лог задания. Туда же не попадал
  отчёт исхода с разделом «Чего не хватает». Итог: причина «0 документов»
  из лога задания не видна в принципе.
- Теперь и прогресс, и отчёт исхода дописываются в `session_log.txt` задания
  (источник «шаг0», без дубля временной метки). Следующий прогон покажет точную
  причину по каждому лоту прямо в файле задания.

## ACRIS: образец страницы при пустом списке

- Если страница результатов ACRIS пришла, но ни одной строки документов не
  распозналось, в причину «Чего не хватает» добавляется образец текста
  страницы (первые слова без тегов) — чтобы отличить «документов по BBL нет»
  от «страница устроена иначе, чем ждёт разбор». Кандидаты по живому случаю
  3870 (0 документов за ~2 с): страница отказа ACRIS, пустой ответ или
  нераспознанная страница — точный ответ даст следующий лог.
