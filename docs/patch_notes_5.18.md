# 5.18 — список моделей RouterAI: Grok 4.7 и 4.6, jev и microsoft

Дата: 2026-11-24.

## Что изменилось

В выборе моделей RouterAI оставлены только четыре:

- `x-ai/grok-4.7` — разбор и страховочная копия Hydra grok-4.7 из 5.17;
- `x-ai/grok-4.6`;
- `typesafe/jev-1.14`;
- `microsoft/microsoft-decision-1.1`.

Удалены `openai/gpt-4.1`, `openai/gpt-4.1-mini`, `openai/gpt-4o`,
`openai/gpt-4o-mini`, `google/gemini-2.5-pro`, `google/gemini-2.5-flash`,
`anthropic/claude-sonnet-4.5` и `deepseek/deepseek-chat`. Модель RouterAI по
умолчанию теперь `x-ai/grok-4.7`; на неё же переведена цель прохода 3 по
умолчанию (была `openai/gpt-4.1`).

## Почему Grok не было видно после 5.17

Модель была добавлена в каталог в коде, но сохранённый у пользователя
`config.json` перекрывал каталог своим старым списком моделей, а миграции
списка для RouterAI не существовало (для Hydra она есть с 4.81.11). Теперь
`load_config` чистит список RouterAI так же, как список Hydra: прежние модели
удаляются, выбранная модель и цели консенсуса на удалённых моделях
переводятся на `x-ai/grok-4.7`. Обновление программы само всё поправит,
`config.json` руками редактировать не нужно.

## Проверка

- Тесты миграции: пустой конфиг даёт ровно четыре модели; сохранённый конфиг
  со старым списком чистится, `selected_model`, верхний `api.model` и цель
  прохода 3 переводятся на `x-ai/grok-4.7`.
- GUI-тест выбора провайдера: у RouterAI видны Grok 4.7 и 4.6, `openai/gpt-4.1`
  отсутствует.
- Полный pytest: **2113 passed, 14 skipped, 2 xfailed**.
