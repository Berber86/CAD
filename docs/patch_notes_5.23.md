# 5.23 — новые модели Hydra: cheap GPT-6.1 и Claude 5.5

Дата: 2026-11-24.

Hydra добавила модели (объявление и фильтр «Только новые» на
https://dashboard.hydraai.ru/models/): `cheap/gpt-6.1-sol`,
`cheap/gpt-6.1-terra`, `claude-haiku-5.5`, `claude-opus-5.5`, `gpt-6.2-astra`,
`gpt-6.2-sol`. Две последние уже были в нашем каталоге (проверка 23.11),
добавлены четыре. Данные — публичный каталог `GET https://api.hydraai.ru/v1/models`
(цены, вход text+image, уровни reasoning_effort), а не только карточки сайта.

Добавлены в большой список Hydra по возрастанию цены миллиона выходных
токенов (модель по умолчанию `grok-4.7` по-прежнему первая):

| Модель | Вход ₽/1M | Выход ₽/1M | Рассуждения (дефолт) | Место в списке |
|---|---|---|---|---|
| `claude-haiku-5.5` | 4.7 | 23.5 | none…xhigh (none) | после `gpt-6-luna` (20) |
| `cheap/gpt-6.1-terra` | 10 | 50 | none…xhigh (none) | после `gpt-5.4-nano` (50) |
| `cheap/gpt-6.1-sol` | 20 | 100 | low…xhigh (low) | после `gemini-3.5-flash-lite` (100) |
| `claude-opus-5.5` | 188 | 940 | low…xhigh (low) | после `gpt-5.4` (600) |

Для всех четырёх добавлены записи `HYDRA_MODEL_REASONING`: уровень
рассуждений по умолчанию, допустимые значения переключателя и цена выхода
(у haiku цена базовая — при входе >100k токенов выход дорожает до 117.5 ₽/1M
по overrides каталога). Контекст новинок 256k–800k токенов, вход text+image —
условиям каталога (Vision + настраиваемые рассуждения) они удовлетворяют.
Миграция `load_config` подхватит новые модели в пользовательские списки сама:
список Hydra пересобирается из каталога.

Итого в списке Hydra 33 модели.
