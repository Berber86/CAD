# Примечания к версии 5.34 (2026-11-25 09:34)

## Что изменилось

**Запрос про соседей повторяется при сбое, а не хоронит задание.**

Живой случай из очереди: запрос к Hydra grok-4.7 про номера соседних
лотов упал с первой попытки (`Request timed out.`), поиск адреса
завершился ошибкой, и всё задание встало — хотя документы ещё даже не
качались. Гонка двух моделей (5.31) шанс успеха повышает, но каждый её
запрос был одноразовым.

Теперь каждый запрос про соседей — и основная модель, и параллельная
Hydra cheap/gpt-6.1-terra — при сбое повторяется сам: до
`NEIGHBOUR_ATTEMPTS = 3` попыток с паузами 2 с и 4 с
(`nyc_portal.NEIGHBOUR_RETRY_PAUSE_SEC`). Повторяется всё: тайм-аут,
кривой JSON, нечисловой ответ модели. В журнал пишется строка
«запрос про соседей к … не удался (…); повторяю — попытка N из 3».
Гонка по-прежнему принимает первый валидный ответ, включая ответ со
второй-третьей попытки. Поиск падает, только когда все попытки всех
участников исчерпаны.

## Проверка
- 2169 passed, 14 skipped, 2 xfailed (было 2166; +3 теста).
- Повтор после тайм-аута спасает одиночный запрос; участник гонки,
  упавший с первой попытки, выигрывает гонку со второй; сдаёмся ровно
  после `NEIGHBOUR_ATTEMPTS` попыток.
- Живьём подтверждает: при хилом провайдере в журнале Шага 0 видны
  строки «повторяю — попытка 2 из 3», и задание после этого доходит до
  сбора PDF вместо ошибки задания.

## Если что-то не так
`git revert` коммита 5.34 одним коммитом: запросы про соседей снова
станут одноразовыми.
